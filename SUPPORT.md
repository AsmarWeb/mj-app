# Support | الدعم

## Where to ask

- **Bugs:** open an [issue](https://github.com/AsmarWeb/murwaj/issues/new/choose) with reproduction steps and redacted logs.
- **Feature ideas:** use the feature-request form and describe the merchant/customer problem.
- **Usage questions:** use the question form after reading the README and linked docs.
- **Security vulnerabilities:** follow [SECURITY.md](SECURITY.md); never use public issues.
- **Community conduct:** follow the private reporting guidance in [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

This repository provides community support for the open-source software. It is not a support desk for an individual customer's purchase, refund, account or delivery. Contact the relevant merchant or service operator privately for those matters.

## Useful context

Include the commit/branch, operating system, PHP/Node versions, database engine, relevant configuration names without secret values, reproduction steps and the smallest redacted error log.

Do not attach `.env`, payment data, API keys, customer information or private downloads. Never send your APP_KEY or change it as a troubleshooting shortcut.

There is no guaranteed response time. Do not assume a public issue authorizes maintainers to access your server or change your data.

## بالعربية

استخدم Issues للأخطاء والأسئلة والاقتراحات التقنية، مع حذف البيانات الحسّاسة. تواصل مع التاجر أو مشغّل الخدمة بشكل خاص لمشكلات الطلبات والمدفوعات والتوصيل. الثغرات وشكاوى السلوك لها مسارات خاصة في الملفات المرتبطة أعلاه.
